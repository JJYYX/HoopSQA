# HoopSQA

**HoopSQA: A Structured VideoQA Benchmark for Basketball Shot Understanding**

This repository is the official project page for HoopSQA, a structured video question-answering benchmark for fine-grained basketball shot-event understanding.

## Overview

HoopSQA focuses on structured semantic understanding of basketball shot events, covering player attributes, shot characteristics, scoring outcomes, and player interactions.

## Dataset

The HoopSQA dataset contains 9,143 annotated basketball shot-event clips, with ten semantic fields for each event.

## Code and Data Release

The dataset annotations, evaluation scripts, and implementation code are planned for public release upon acceptance of the paper.

Video clips will be made available for academic research subject to applicable copyright and licensing restrictions.
